Follow the steps below to install the remote support tool so your technician can connect to your computer and help you right away.

Download for Windows Windows

This installer is already set up to connect to your technician’s server — no configuration needed. Just download, run, and read your ID number to your technician.

Download Remote Support (Windows)

Windows — Step by Step

1
Click the Download button above. The file will save to your Downloads folder.
2
Open the downloaded file and click Install when asked. If Windows shows a security prompt, click Yes to allow it.
3
RustDesk will open and show you a large ID number. Read that number to your technician — that’s all they need to connect.

Mac — Step by Step

1
Go to rustdesk.com and download the macOS version of RustDesk. Open the downloaded file and drag the app to your Applications folder.
2
Open RustDesk, then click the three-dot menu (⋯) and choose Settings → Network → ID/Relay Server.
3
In the ID Server field enter: mikeremote.tplinkdns.com. Leave the Relay and API fields empty.
4
In the Key field paste: IEMqlZ+k5LoHASWDtogcGKtTBDEW6KNe1VRWytm1WDs=
5
When macOS asks for Screen Recording and Accessibility permissions, click Allow for both. Then read your ID number to your technician.
